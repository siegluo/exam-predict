# exam-predict - 考试预测系统

基于机器学习的考试成绩预测应用。

## 项目结构

```
├── frontend/          # Next.js 前端
├── frontend-wechat/   # 微信小程序
├── java-backend/     # Spring Boot 后端
├── python-backend/   # FastAPI AI/预测服务
├── deploy/            # Docker 部署配置
├── scripts/           # 数据导入脚本
└── data/             # 示例数据
```

## 技术栈

- **前端**: Next.js, React, TypeScript
- **微信小程序**: 原生开发
- **后端**: Spring Boot (Java), FastAPI (Python)
- **AI**: 机器学习模型预测
- **部署**: Docker, Nginx
